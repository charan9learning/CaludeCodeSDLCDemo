# Claude Code SDLC Demo

A demonstration project showcasing software development lifecycle (SDLC) practices with Claude Code.

## Overview

This project serves as a reference implementation for using Claude Code in a complete software development workflow, including:

- Project initialization and setup
- Development with AI-assisted coding
- Version control and git workflows
- Code review and quality assurance
- Documentation and maintenance
