# CLAUDE.md - Claude Code SDLC Demo

## Project Overview

This is a demonstration project for Claude Code SDLC practices. It showcases best practices for software development lifecycle when working with Claude Code.

## Project Goals

- Demonstrate effective use of Claude Code in development workflows
- Show proper git and version control practices
- Provide a template for SDLC implementation
- Document development standards and conventions

## Development Guidelines

### Git Workflow

- Use descriptive commit messages
- Keep commits focused on single features or fixes
- Follow conventional commit format when possible
- Test changes before committing

### Code Quality

- Maintain clean, readable code
- Include comments for non-obvious logic
- Follow project naming conventions
- Review code changes before merging

### Documentation

- Keep README.md updated with project changes
- Document new features and APIs
- Maintain CLAUDE.md for ongoing guidance
- Include examples in documentation

## Claude Code Integration

### Useful Commands

- `/help` - Get help with Claude Code features
- `/config` - Configure settings
- `/fast` - Toggle fast mode

### Best Practices

- Use Claude Code for code generation and review
- Leverage AI assistance for documentation
- Ask for code review before major changes
- Use structured tasks for complex implementations

## Working with AI Assistance

### When to Use Claude Code

- Generating boilerplate code
- Writing tests and documentation
- Code review and refactoring
- Debugging and troubleshooting
- Architecture and design decisions

### Code Review Process

1. Make changes with Claude Code assistance
2. Request code review for complex changes
3. Address feedback and iterate
4. Commit when satisfied with quality
